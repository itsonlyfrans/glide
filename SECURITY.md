# Security policy

Glide carries your keystrokes and clipboard between computers, so security reports get priority.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/itsonlyfrans/glide/security/advisories/new). Include what you found, how to
reproduce it, and which versions and operating systems are affected.

You will get a reply within a few days. Fixes are released as a signed update, and reporters are credited unless they
ask not to be.

Only the latest release receives security fixes. The security design is described in [`docs/SPEC.md`](docs/SPEC.md)
(section 3).
